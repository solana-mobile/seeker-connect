# Contributing to Seeker Connect

Thanks for your interest in improving Seeker Connect!

## Contribute through issues

**Pull requests are limited to repository collaborators.** If you've found a
bug or have an idea, [open an issue](https://github.com/solana-mobile/seeker-connect/issues/new)
instead.

Every change costs a maintainer two things: reproducing the problem, and then
verifying that the change fixes it. A good issue lets us do the reproduction
once and write the fix ourselves, so a detailed report is the most valuable
contribution you can make.

If you already know the fix, describe it in the issue: the root cause, the
files involved, or a code snippet.

## Writing a good issue

- **Include a minimal reproduction.** Use one of the example apps
  (`js/examples/example-web`, `js/examples/example-react-native`,
  `android/example`) where possible, and list the exact steps.
- **Keep it scoped.** One problem per issue.
- **Share versions.** Include the SDK package versions, the wallet app, and the
  device or emulator you tested on.

Usage and how-to questions belong on
[Solana Stack Exchange](https://solana.stackexchange.com/questions/ask) with the
`solana-mobile` tag, or the [Solana Mobile Discord](https://discord.gg/solanamobile).
